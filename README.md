Nightclub Reservation System (.NET)
swan.JPEG
This project is a Nightclub Reservation System developed using .NET. It provides a complete platform for users to create accounts, log in, and reserve tables in a nightclub based on available time slots, number of people, and seating preferences.

The system also allows users to browse and order drinks from categorized menus, manage or cancel reservations, and receive booking confirmations. It is designed to simulate a real-world nightclub management experience with a focus on usability, organization, and efficient reservation handling.
